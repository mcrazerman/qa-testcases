Тест-кейсы для проекта [restful-booker](https://restful-booker.herokuapp.com/apidoc/index.html). 
Проект представляет собой имитацию API для бронирования номера в отеле.

> Примечание: в тест-кейсах ожидаемые результаты составлены не на основе документации, а исходя из здравого смысла и стандартных практик.
